# 结论与数据边界

## 得到支持的结论

- 在明确列出的 POI 理解任务、有限真实训练对照和共同示例上下文中，合成训练信号得到相近的学生成绩。
- 从生成、监督资格、训练到量化导出与重载的多个环节已实际执行，并留下配置和原始输出。
- 缺失值、并列、位置、示例、输出长度和解码有效性会改变结果解释。
- 一检查点的 INT8 减小权重且保住72题总正确数；此设置不提速。NF4存在准确率损失。

## 尚未证明

- 新生成器稳定胜过旧生成器，或合成数据在统计上等效于真实训练数据。
- 所有任务、所有长尾和真实 outlier 都能保留；少量真实 outlier 不能支持可靠估计。
- 已解决复杂规划、反思或交互式策略蒸馏。
- 差分隐私、成员推断安全、不可重建，或整个历史研究从未外发真实题。
- 单张卡、小样本、串行延迟能够代表其他硬件或生产吞吐。

## 发布与研究资产

本仓库发布代码、人工构造的测试样例、汇总指标及来源哈希。真实记录、拟合表、检查点、逐题原始输出、教师请求、凭证和本地授权清单留在研究归档。

历史上90道和72道原始题曾作为单独批准的公开代理例外外发；不能将那些调用当成零原始记录外传的证据。生成数据也是本地真实数据的派生物，离开本地前仍须取得明确范围授权。相似度筛查不是正式隐私保证。

原始Final边界按各次授权执行，已访问的理解题Final不得重新包装成未见测试集。公开的汇总不授权读取或发布剩余封存材料。
