# 实验结果与证据

## 同题数补充评测

固定 Qwen3.5-2B，68 个独立监督题、136 次更新，训练顺序 831/832/833；相同 1,154 道理解题，601 个数值组。

| 训练来源 | 顺序 831 | 顺序 832 | 顺序 833 | 平均正确率 |
|---|---:|---:|---:|---:|
| 真实训练题 | 1003/1154 (86.92%) | 1041/1154 (90.21%) | 1007/1154 (87.26%) | 88.13% |
| 旧生成器 | 1026/1154 (88.91%) | 1049/1154 (90.90%) | 1028/1154 (89.08%) | 89.63% |
| 新生成器 | 1033/1154 (89.51%) | 1054/1154 (91.33%) | 1022/1154 (88.56%) | 89.80% |

同步重排位置与选项后的平均正确率：真实 **88.50%**、旧生成器 **90.15%**、新生成器 **89.60%**。原题与重排题是同一批题的两种视图，不是 2,308 个独立样本。

八道真实示例是共同训练与评测上下文；不能称为完全无真实示例流程。此处“合成替代”指监督目标题来源。Final 已在前一轮暴露，本次模型在首次暴露前已固定，补测无训练或选择；不能称为全新独立验收。

新旧差异小，方向随视图与训练顺序变化。新相对真实的条件置信区间触及或跨过零；没有证明优越性、等效性或非劣效性。详见 [汇总](../results/matched68.json)。

## API 教师标注

1,088 次初始调用得到 1,087 条有效且与规则一致的标签；一条输出截断，经单独授权再调用一次后补齐。最终 4,352 个旋转视图的目标与本地规则版本一致，输入与计划也相同。因此不能将复用的执行视为独立重复训练，也不能用这批标签估计非零教师噪声。归档中缺少共享执行完成文件，不在这里宣称另有三次独立教师训练全部完成。[核验摘要](../results/teacher-labels1088.json)

## 72 题示例敏感性

固定 9 个已训练检查点，在同一组 72 题 / 50 数值组上比较无示例、真实8、合成8。训练未改变，开发中使用后的这组题不能再视为独立最终集。示例替换结果与完整逐模型汇总见 [examples72.json](../results/examples72.json)。此实验说明上下文是重要因素，不证明历史训练未使用真实示例。

## 部署测量

同一合成训练检查点 `current_n68_s831`、step136，固定合成8上下文、greedy1024、L40S。BF16 66/72、INT8 66/72、NF4 61/72；INT8 有一增一失，NF4 五失。权重大小、峰值 PyTorch allocated 显存、串行延迟分别保存，不混称显存或吞吐。[量化](../results/quantization72.json)

vLLM BF16 提示去重：约 6,000 → 3,851 token；不启用缓存时中位延迟 0.2425 → 0.1856 秒，总正确数均为 66/72，但三条回答改变、一增一失。去重提示启用缓存后 0.1748 秒，缓存开关之间 72 条输出 token 一致。只是一检查点、小样本、固定硬件与串行设置。[提示与缓存](../results/prompt-cache72.json)

## 规划负面结果

未微调 2B 的原版道路 QA 前200：19正确、50与作者参考不一致、131无效。131题都经历三次8192 token截断；517次尝试中448次截断，消耗约95%的生成token。归档输出重放与独立解析均吻合，重复输出的深层原因尚未隔离。不能把正常作答子集的19/69换成全体成绩。[离线审计](../results/road-first200.json)

这不是微调理解模型的成绩，也不是完整500题结果；本仓库没有把不完整的规划任务报告为成功。
