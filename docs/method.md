# 方法与流程

## 研究问题

本地真实记录不直接作为常规外部教师请求，合成题能否提供足够有效的学生训练信号？训练数据替代与“真实＋合成”增强分开评估；学生效用、教师质量、分布覆盖、披露风险分开报告。

## 六个阶段

1. **本地任务与划分。** 确定题面、目标、候选项、缺失值与并列规则；保持拟合、开发和最终评测边界，数值组用于检查重复与相关性。
2. **生成与质量检查。** 保存旧生成器，比较联合关系、缺失值状态与可观测数值的表示；改进生成器的覆盖与表达。更好的分布指标不直接等于更高的学生分数。
3. **监督资格。** 理解题可以用显示数值精确验证；规划题需要足够的可见状态与明确奖励、时域。近似搜索结果不能自动成为可信金标准。
4. **教师监督。** 明确允许发送的批次、供应商、模型、输出长度和费用上限；记录失败和恢复。精确规则监督单独保留，用于区分生成质量与教师噪声。
5. **学生训练与验证。** 固定初始化、来源题数、更新次数及训练顺序；同步重排位置、引用和选项。报告所有顺序，区分正常作答、参考不一致、解析失败、截断。
6. **部署。** 固定检查点后验证合并、量化、重载、提示压缩、缓存；同时记录准确率、权重大小、显存与延迟。
